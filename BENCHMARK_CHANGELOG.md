# Benchmark changelog

Changes to the benchmark itself (world, events, ground truth, harness,
evaluator). Contestant changes are never recorded here. Per CLAUDE.md rule 7
and EXPERIMENT.md §14, a change to a frozen scenario requires a new scenario
version, and each entry says which runs it invalidates.

## 0.1.0 (Milestone 1)

- Harness 0.1.0 and evaluator 0.2.0. Schemas: `tab.event/1`, `tab.action/1`,
  `tab.trace/1`, `tab.ground_truth/1`, `tab.scores/1`, `tab.scenario/1`,
  `tab.run/1`, instructions `tab.instructions/1`.
- Seed world `tasklane` (`world/seed_repo`).
- Scenario `smoke_v1` (frozen, `held_out: false`), generated by
  `world/ground_truth/smoke_v1/build_scenario.py`.
- Benchmark fixes applied before the first freeze, following design review.
  No contestant had run, so no results are invalidated.
  - Seed: the reconcile job heals itself after exhausting its retries, so the
    PayGate maintenance notice is a true negative control.
  - Seed: tests no longer pin values that routine world events change.
  - Seed: ADR-0001 no longer rests on instance memory, which the tier-upgrade
    event changes.
  - Seed: ADR-0002 records dedicated-vCPU timing.
  - Seed: the vendored SDK documents `current_period_end` while `past_due`.
  - Scenario: uniform 3-step windows, negative controls after the last
    trigger, and behavioural hidden tests as remediation criteria. Workspace
    suite health is reported separately as hygiene.
